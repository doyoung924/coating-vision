## 1. 프로젝트 개요

- 전극 코팅 표면 결함을 검출하고 결함 유형에서 원인 공정 인자를 역추적하여 점검 항목을 제시하는 인라인 검사 시스템
- 이상 탐지(A3 밝기 표준편차), 결함 검출(YOLOv8n 핀홀), 시맨틱 세그(U-Net+ResNet34 크랙·박리), SPC 관리도, 규칙 기반 Advisor, Flask 대시보드(Oracle 11g 백엔드)로 구성
- 대시보드는 로그인 · 검사 실행 · 이력 · SPC · 게시판 · 관리 기능 포함

### 데이터셋

- **CoatingVision** (Sampath et al., *Sci Data* 2026, DOI 10.1038/s41597-025-06419-1)
- 라이선스 CC BY-NC-ND 4.0
- 2,227 patch (480×640 RGB), 슬롯다이 코팅 / Vulcan 카본 / Nafion / PTFE (연료전지 계열)
- 마스크 RGBA 4채널 {0,255}: crack(ch0) · delam(ch1) · pinhole(ch2) · unclassified(ch3)
- 파일명에 공정 조건 인코딩 (run · gap · position · frame · patch), 파싱 성공률 100%
- 원본 프레임 수 367개, 각 프레임에서 3×3 격자 잘라내어 patch 최대 9개 (patch_N ∈ 0~8)

### 규모·기간

### 비용 민감도 (§22-5)

- 총비용 = C · FN + FP, C = 미검비용/과검비용
- **A3 최적 L**: C ∈ [1, 10] → L=5.0 / C ∈ [30, 100] → L=2.3 (C≈15~25 구간에서 급변)
- **세그 최적 L**: C ∈ [5, 100] → L=4.5 안정 (A3 대비 완만)
- **한계**: 비용비 C 는 라인·제품 종속. 이 프로젝트에서 확정 불가. 민감도 도표로만 인용

### 4-1. 마스크 병합 가설 → 기각 (§4-1)

### 4-2. 넓은 갭 핀홀 메커니즘 → 관측되지 않음 (§4-3)

### 4-14. delam 학습 불가 예상 → 학습됨 (§20-4)

- **예상**: train 121 patch · 픽셀 0.127% · 833:1 불균형이면 delam 학습 불가

### 4-16. "A3 가 프레임 단위 F1 에서 세그보다 우세" 가설 → 정정 (§22-9, 2026-09-15)

- **가설** (§22-4 잠정): 프레임 단위 예측 정의 a_any 에서 A3 F1 0.212 > 세그 F1 0.153 이므로 프레임 단위 판정에서는 A3 가 우세
- **검증**: 예측 정의를 정답과 대칭인 c_frame_agg 로 재산출 (예측도 프레임 단위 mean/max 로 관리도)

- **판정**: 원 가설은 예측 정의 a_any 의 비대칭 편향에서 나온 인공물. 대칭 조합이 대표

### 4-17. b_majority 부적합 판정 → 정정 (§22-13, 2026-09-15)

- **초기 관측** (§22-9): b_majority 6 조합 전부 recall 0.000. "프레임 내 과반 조각이 알람인 경우 없음, b_majority 는 이 데이터에 부적합"
- **검증**: `pred_b_majority` 코드에서 `patch_alert_indices` (min_gap=10 병합 후) 를 입력으로 사용하는 것을 발견. raw alert (병합 없음) 로 재산출
- **결과**: 프레임 367 개 중 raw 기준 과반 알람 프레임 A3 103 · 세그 133 개 존재. 정정 후 b_majority F1 세그 max 0.184, A3 max 0.197
- **판정**: b_majority 자체가 부적합이 아니라 병합 인덱스를 입력으로 쓴 코드 오류. 여전히 대칭 c_frame_agg 가 우세이나 결론은 유지 (§22-9 대칭 조합 우위)

- **정정**: CLAUDE.md, README.md, kpi_headline.json, app.py, 템플릿, experiment_log 등 확산 지점 전부 정정. patch 당은 0.11 × 70 ≈ 8 ms

### 6-7. EWMA 초기화 버그 (§9-1)

### 6-8. 저자 라벨 대비 IoU 매칭 실패 (§10-2, §10-3)

- **발견**: 마스크→YOLO 자동 라벨 검증에서 IoU 0.3 기준 재현율 0.239, 정밀도 0.289

### 6-9. IoU 매칭 임계 편의로 FN·FP 이중 카운트 (§22-DET-9, 2026-09-16)

## 8. 한계와 미해결

### 8-1. 수치의 낙관 편향

- 이상 탐지 벤치마크는 애매한 patch 배제 (정상 margin 4px, 결함 82px/15px 이상만)
- 조명 조건 단일 (R1 94%)
- 실제 인라인 검사 성능은 이보다 낮음

### 8-2. 도메인 갭

- CoatingVision 은 Vulcan 카본·Nafion·PTFE (연료전지 계열), 배터리 전극 (NMC/PVdF/Al foil) 아님
- 전이 가능: 결함 형성 물리, 기하 형태 지표, 인과 구조 방향성, 방법론 프레임
- 전이 불가: 활물질 광학 특성, 조명·노출 조건, 절대 결함 허용 기준, SPC 관리한계

### 8-3. 데이터 제약

| 제약 | 영향 |
|---|---|
| 정상 이미지 44장 (2.0%), 25장이 600µm 집중 | patch 기반 접근 불가피 |
| R1 단일 런 94% | 물/IPA 용매비 효과 검증 불가 |
| patch 단위 데이터 | 핀홀 밀도 측정 불가 |
| 갭 범위 600~1100µm | U자형 좌측만 커버 |

### 8-4. R7/700 특이성 미해결

- 같은 700µm 인데 라벨률 프로파일 다름, A3 vs crack Spearman 0.153
- 원인 후보 (런 vs 위치): 표본 132장 + 위치 다름 교란
- 분리 불가로 Advisor 는 관측만 보고

### 8-5. 임계값 임의성

- SPC 공정능력 판정 중심선 0.25 는 임의값, 실제 라인에서는 제품 규격에서 도출
- Advisor 형태 임계 (종횡비 1.2, roundness 0.72·0.78) 는 R1 단일 런에서 도출

### 8-6. 핀홀 검출 조건

### 8-7. 세그 관련 한계

- delam 은 시드 편차·best epoch 편향으로 안정성 한계 (자소서 주 지표 제외)

- R7/700 정답 알람 0 → 세그 R7 이전성은 "오탐 안 냄"만 확인, 진짜 양성 재현율 미검증
- 세그 CPU 450 ms/patch 로 인라인 부적합, GPU 측정치 없음

### 8-8. 프레임 단위 F1 0.600 이 실용 수준인지 유보 (§22-9)

### 9-11. 격리된 테스트

- **규칙**: 기존 데이터 오염 금지, 모델 로드 없음, 통과시키려고 기능 코드 변경 금지
- **사례**: `pytest_*` UUID 접미사 사용자, finalizer 가 CASCADE 삭제, 3회 연속 실행 후 잔여 0 검증

### 9-12. 정답·예측 집계 방식은 대칭이어야 (§22-9)

- **규칙**: 판정 단위를 옮길 때 정답과 예측 모두 같은 집계 방식이어야 함. 정답만 옮기고 예측은 그대로 두면 F1 이 지표가 아니라 편향값이 됨
- **사례** (§22-2 → §22-9): 프레임 단위 재집계 시 예측을 patch OR (a_any) 로 유지하면 F1 0.153. 예측을 정답과 같은 프레임 mean/max 로 재집계하면 F1 0.600. 대칭 조합이 기본이며 나머지는 참고

### 9-13. 극단값 (0.000, 100%) 은 코드 오류 신호 (§22-13)

- **규칙**: 6조합 전부 recall 0.000 같은 극단값은 데이터 특성보다 조건식 성립 불가 또는 입력 부적합을 시사. 이런 값이 나오면 정의 재확인 우선
- **사례** (§22-13): b_majority 전부 0.000 → 병합 인덱스를 프레임 카운트에 쓴 것이 원인. raw 인덱스로 정정. 실제로는 A3 103 · 세그 133 프레임이 과반 알람 상태

### 9-14. 매칭 임계·집계 단위는 인용 시 반드시 병기 (§22)

- **규칙**: 지표값을 인용할 때 매칭 임계 (IoU 0.5, ±5 인덱스 창), 집계 단위 (patch 시계열, 프레임), 정의 (a_any, b_majority, c_frame_agg) 를 함께 명시. 절대값 인용은 오도 가능
- **사례** (§22-DET-12): "과검률 16.5%" 를 (a)/(b)/(c) 그룹 병기 없이 인용 금지. "IoU 문턱 0.5 기준" 명기 필수. "세그 recall 1.000" 은 "patch 시계열 min_gap=10, ±5 매칭창" 조건 병기 필수
